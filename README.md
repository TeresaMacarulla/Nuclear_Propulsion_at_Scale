# UiO_Summer_Project--Nuclear_Propulsion
This repository contains code developed as part of the NNRC Summer project 2026, funded by UiO:Energy and Environment.
This summer study will examine what it would take, at a system and infrastructure level, to
deploy and operate approximately 600 nuclear-propelled merchant ships, and how such a fleet
could realistically be scaled between 2035 and 2050. The focus is on fuel supply, supporting
infrastructure, and deployment feasibility, rather than on detailed reactor or ship design.

### Python virtual environment

For this project, a local Python virtual environment was created using `venv` and `pip`. The environment itself is not included in the repository, so each user should create it locally. To set it up, run:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
